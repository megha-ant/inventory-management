No database and no persistence: all data is loaded into module-level Python lists at startup and filtered per request. The frontend talks to the backend directly (no Vite proxy), relying on the backend's open CORS policy.

Data Flow — Filter Change to Rendered Data

User changes one of the 4 global filter selects (Time Period, Warehouse, Category, Order Status).client/src/components/FilterBar.vue — rendered globally in App.vue
The select is bound via v-model to shared singleton refs: selectedPeriod, selectedLocation, selectedCategory, selectedStatus.client/src/composables/useFilters.js — module-level refs shared by all views
Each view watches those refs and re-runs its loadData() when any value changes.Dashboard.vue, Orders.vue, Inventory.vue, Demand.vue, Spending.vue
getCurrentFilters() maps UI refs to API params: location → warehouse, period → month, category → category, status → status (values of "all" are skipped).client/src/composables/useFilters.js
The API client builds the query string and issues an axios GET to http://localhost:8001/api/....client/src/api.js
FastAPI endpoint applies apply_filters() (warehouse exact match; category/status case-insensitive) and filter_by_month() (YYYY-MM or Q1–Q4 2025) over the in-memory lists, validates with Pydantic, and returns JSON.server/main.py + server/mock_data.py
The view assigns the response to local refs (e.g. allOrders, inventoryItems); computed properties derive chart/table data and the template re-renders.client/src/views/*.vue

Observations & Known Gaps

  • Gap client/src/api.js declares task endpoints (/api/tasks, GET/POST/PATCH/DELETE) and purchase-order endpoints (/api/purchase-orders) that are not implemented in server/main.py — the Pydantic models and an empty purchase_orders.json exist, but no routes.
  • Gap Backlog.vue exists but is not registered in the router, so it is unreachable from the UI.
  • Inconsistency Reports.vue calls the backend with raw axios and hardcoded URLs instead of going through api.js.
  • By design Inventory has no time dimension, so /api/inventory ignores the Time Period filter; spending endpoints take no filters at all.
  • By design Revenue goals used by the dashboard: $800K per single month, $9.6M YTD across all months.
